# 🎙️ Prepr AI

**The Future of Interview Preparations.** Prepr AI is a voice-first SaaS platform designed to conduct automated, 1-on-1 technical interviews and oral exams using AI. It bridges the gap between traditional study and real-world communication by using specialized voice agents to assess candidate knowledge in real-time.

---

## 🚀 Features

- **Adaptive Voice Interviews:** Real-time, 1-on-1 conversations powered by **Vapi.ai**.
- **Smart PDF Parsing:** Upload a resume or exam material, and the system automatically builds a knowledge graph for the examiner using `pdfjs-dist`.
- **AI Recruiter Summary:** Automatic performance analysis and 1-5 star scoring using **Gemini Flash**.
- **Secure Dashboards:** Personal mission control for tracking past sessions and performance trends.
- **Glassmorphic UI:** A premium, "Editorial White" aesthetic built with **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Authentication:** Clerk (Identity & Access Management)
- **Database:** Supabase (PostgreSQL with Row Level Security)
- **Voice Engine:** Vapi.ai (Web SDK & Webhooks)
- **Intelligence:** Google Gemini  Flash (Transcript analysis & scoring)
- **Infrastructure:** Vercel, ngrok (for local webhook tunneling)
